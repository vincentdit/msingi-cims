How the mock answers

By the last digit of the CSEE index number:
  • 7: queried (name does not match NECTA); verified once resubmitted with remarks
  • 9: not verified (minimum entry requirements)
  • 3: verified, also admitted elsewhere; the applicant needs the confirmation code shown in the batch
  • 5: verified, but takes three times as long
  • any other digit: verified
Endpoints

NACTVET (JSON POST with authorization and api_code): /nacteapi/index.php/api-out-service/admissionverification, …/admissionverificationresults, …/admissionconfirmation; student registration …/studentregistration and …/studentregistrationstatus (a student without a verification number is queried); results …/resultsubmission and …/resultsubmissionstatus (a row without a verification number or a grade is queried).

Developer: GET /mock/batches, GET /mock/confirmation-codes/{index}, POST /mock/confirm-elsewhere/{index}, POST /mock/outage?on=true|false, POST /mock/reset (use - for / in index numbers).
